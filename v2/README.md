# 视频审核评测集 v2

**每个用例 = 一份创意要求 + 一条视频 + 一个结论（放行 / 拦截）。** 只收人在正常观看时能明显看出来的问题；看不出来的差异不算错误。

```
v2/
├── cases/<用例>/brief.json   创意要求：产品、要求的动作和效果、文案（审核时作为输入）
├── cases/<用例>/truth.json   结论：verdict、错误类别与描述、来源、确认程度
├── videos/<用例>.mp4         视频
├── INDEX.md                  全部用例一览
├── taxonomy.json             错误类别
└── sources.json              由哪些素材组装而来（node src/build-v2.mjs --config v2/sources.json --out v2）
```

## 错误类别

| 大类 | 类别 | 例子 |
|---|---|---|
| **A 与创意要求不一致** | A1 产品不一致 | 耳机没有要求的柄、杯盖多了提环、产品变色、多出部件、Logo 不对 |
| | A2 动作方式不符 | 要求滑开却直接掀开、动作反了、要求的动作没有完成 |
| | A3 交互对象不符 | 要求按琴键却摸琴身、要求按电源键却按了别的键 |
| | A4 使用方法不符 | 要求喷在手腕却喷向空中 |
| | A5 氛围情绪不符 | 要求轻松愉快，成片清冷惨淡 |
| | A6 场景环境不符 | 要求户外公园，成片在室内健身房 |
| | A7 文案字幕不符 | 字幕写 50W，要求是 15W |
| **B 明显的画面问题** | B1 物理或因果不合理 | 水往上流、水倒进去杯子却不满、没按键灯就亮了 |
| | B2 画面跳变 | 瞬移、物体凭空消失又出现、画面回到开头、先出结果再出动作 |
| | B3 技术故障 | 黑场、冻帧超过 1 秒、全片无声 |
| | B4 画面崩坏 | 明显的乱码文字、物体扭曲 |

## 用例从哪里来

| 来源 | 做法 | 为什么结论可靠 |
|---|---|---|
| `pair` 对比对 | 同一场景生成两条只在一个维度不同的视频（例如有柄 / 无柄、按电源键 / 按小键），交叉配对：要求与视频同侧为放行，异侧为拦截 | 每条视频只需确认「如实表现了自己那一侧」，错误由配对本身决定，必然明显 |
| `edit` 确定性注入 | 在干净底片上剪辑或局部合成出错误（倒流、瞬移、黑场、多出部件、错误字幕…），只保留明显（V1）的 | 错误位置由操作直接算出，并通过逐帧真值校验 |
| `base` 底片原片 | 底片本身带人工确认的问题（没站起来、手没离开画面…） | 人工复核确认 |
| `generated` 提示词生成 | 模型直接生成的明显错误（伪文字、Logo 拼错） | 逐条看过，只收明显的 |

`truth.json` 的 `verified_by`：`human` 人工确认，`claude` Claude 看帧复核（待人工确认），`none` 未复核。
