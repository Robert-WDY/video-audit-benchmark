# 样本

首批两轮试验的全部产出：MiniMax H3（自建池，720p，9:16，6 秒）生成的原始视频，以及在这些底片上用剪辑注入得到的样本。打开 `showcase/index.html` 可以逐条播放，并对照真值时间轴查看。

| 目录 | 内容 |
|---|---|
| `generated/` | H3 原始输出 11 条（`场景__错误__seed.mp4`）及请求记录（含完整提示词和 seed） |
| `batch1/` | 以 `S03__base__seed20261119` 为底片的 17 个用例，9 个已渲染 |
| `batch2/` | 以 S03、S05、S07 的 seed20261120 底片为底的 57 个用例，36 个已渲染 |
| `showcase/` | 展示页和压缩后的预览视频 |

`batch*/` 的结构与 `node src/cli.mjs build` 的输出一致：`cases/<用例>/` 下有 `gen.json`（怎么做出来）、`input.json` / `input.script.json`（审核输入）和 `truth.json`（真值）；`videos/<blind_id>.mp4` 是渲染结果，文件名不透明，可直接用于盲审。可以直接在这两个目录上运行 `sheets`、`reconcile`、`finalize`、`score`（`--out samples/batch2`）。需要手工制作的用例（提示词诱导、参考图编辑、实拍干扰项）没有渲染，见各用例的 `gen.json.manual_tasks`。

## 初步复核（Claude 看帧，未经人工盲审）

所有 `truth.json` 的 `annotation_status` 仍是 `pending`。下面是看帧得出的初步结论，正式真值以人工复核为准。

**正确底片**

| 视频 | 结论 |
|---|---|
| `S03__base__seed20261119` | 不干净。画面中有两个保温杯（脚本只有一个，SA6）；倒水时右侧杯子消失、桌上出现杯盖（TC2，约 1.0–1.6s），放回时又出现（约 4.9–5.4s）。batch1 的所有用例都继承这些意外错误 |
| `S03__base__seed20261120` | 干净。提示词加了「每种物体只有一个」之后不再多出物体 |
| `S04__base__seed20261119` | 基本干净 |
| `S05__base__seed20261120` | 干净 |
| `S07__base__seed20261120` | 待判：按键期间（约 2.0–3.8s）音箱布面变红褐色，可能是 PF1 颜色漂移，也可能是光照 |

**提示词诱导**

| 视频 | 目标错误 | 结论 |
|---|---|---|
| `S03__S03.I6__seed20261119` | PH2 水流穿透杯壁 | absent，水正常倒入 |
| `S04__S04.I5__seed20261119` | PF3 三只耳机 | absent；背景包装盒文字「Peol」与产品名 Pebl 不符，待判 PF4/VT1 |
| `S04__S04.I5__seed20261120` | PF3 三只耳机（重做） | absent；合盖时指示灯已亮，待判 SA1 |
| `S02__S02.I6__seed20261119` | PH4 六根手指 | absent，手背朝镜头看不出 |
| `S02__S02.I6__seed20261120` | PH4 六根手指（重做） | absent，掌心朝镜头，清楚是 5 根 |
| `S08__S08.I5__seed20261119` | VT1 罐身乱码 | present，约 1.5s 起罐身出现读不通的伪中文 |

提示词诱导 6 条只成功 1 条；剪辑注入 45/45 渲染成功，时长与真值一致。

纯声音错误（静音）的样本画面与正确底片或对应单错误相同，这是有意保留的：它测的是审核能不能听出来。这些用例在 `truth.json` 里有 `same_picture_as` 字段指明画面和哪条相同。

生成画面中的耳机、音箱外形与市面产品相似，均为模型生成，场景中的品牌（LUMO、Pebl、Volt、Hum、AURA）均为虚构。
